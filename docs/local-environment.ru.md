# Локальная среда Twenty

Стандартный Compose запускает закреплённый upstream-образ Twenty, PostgreSQL, Redis и worker Twenty. Новый том PostgreSQL инициализируется из локального снимка базы, в который входят workspace и настраиваемая учётная запись администратора.

Этот Compose не запускает orchestrator worker или Codex App Server. Выбранная интеграция NestJS/Codex будет отдельным компонентом; в этом checkout она пока не реализована.

## Запуск

1. Проверьте локальные параметры подключения и секреты в приватном файле `.env`.
2. Запустите стек и дождитесь healthcheck сервера:

   ```sh
   docker compose up -d --wait
   ```

3. Откройте `http://localhost:3000` и войдите с учётными данными администратора, указанными ниже. Существующие тома базы сохраняют текущие учётные записи.

## Поведение и ограничения

- `IS_MULTIWORKSPACE_ENABLED` по умолчанию равно `false`; регистрация ограничена поведением локальной конфигурации workspace.
- Upstream-образ закреплён через `TAG` (по умолчанию `v2.53.1`). Перед сменой версии проверьте совместимость.
- Healthcheck Compose проверяет endpoint сервера. Он не проверяет создание учётной записи или настройку workspace.
- Храните `.env` приватно: в нём могут быть API credentials и локальные секреты.

При первой инициализации пустого тома PostgreSQL официальный entrypoint Postgres выполняет `entrypoint-initdb/00-extensions.sql`, затем `entrypoint-initdb/10-default.sql`. SQL-dump — снимок локальной базы `default`. Скрипты инициализации не запускаются повторно при подключении существующего тома `db-data`; для повторной инициализации нужно осознанно заменить этот том.

Скрипт `20-default-admin.sh` после импорта задаёт email и bcrypt-хеш пароля из `DEFAULT_ADMIN_EMAIL` и `DEFAULT_ADMIN_PASSWORD`, а также синхронизирует email в записи участника workspace. Скрипт проверяет фиксированный ID участника workspace и выполняет оба обновления в одной транзакции; при ошибке проверки или обновления изменения откатываются. Значения Compose по умолчанию: `admin@lvh.me` и `LocalTwentyAdmin2026`. Чтобы заменить их, задайте переменные в `.env` до инициализации пустого тома. Эти локальные значения предназначены только для разработки. Изменение `.env` не меняет учётные данные в уже инициализированной базе.
