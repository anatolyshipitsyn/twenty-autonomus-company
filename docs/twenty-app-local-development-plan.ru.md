# План создания Twenty app для локальной разработки

## Цель

Создать отдельный Twenty app-пакет, подключить его к локальному Twenty и получить повторяемый цикл разработки и синхронизации. Приложение расширяет workspace; оно не заменяет сервер Twenty и не становится частью NestJS-воркера.

## Текущее состояние

- В checkout оркестратора нет собственного `package.json`; app создан отдельным пакетом в `../autonomus-company`.
- Локальный сервер из `docs/local-environment.md` отвечает на `http://localhost:3000/healthz` кодом HTTP 200.
- Создан standalone Twenty CLI 2.54.3; ему требуется Node.js ≥24.5. В текущей среде установлен Node.js 24.12.0 через mise.
- npm-slug: `autonomus-company`; отображаемое имя: `Autonomus Company`.
- Назначение: локальная разработка Twenty-приложения для оркестратора автономной компании.
- Пакет создан, зависимости установлены, remote `autonomus-local` подключён к workspace `Demo`, начальная версия успешно синхронизирована.

## Этапы

1. **Зафиксировать идентичность приложения — выполнено.** npm-имя `autonomus-company`, имя `Autonomus Company`, назначение — локальная разработка приложения для оркестратора. Пакет расположен отдельно от кода оркестратора.
2. **Подготовить инструменты — выполнено.** Установлен Twenty CLI 2.54.3, выбран Node.js 24.12.0, зависимости установлены Yarn 4.18.1. Глобальная команда находится вне `PATH`, поэтому в этой среде CLI запускался через полный путь.
3. **Сгенерировать каркас — выполнено.** Выполнен `twenty app init` с указанными именем, путём и описанием; `yarn install` завершился успешно.
4. **Подключить локальный remote — выполнено.** `autonomus-local` подключён к `http://localhost:3000` и workspace `Demo`. Существующий remote `local` (порт 2020) не изменён; исходное значение remote по умолчанию восстановлено.
5. **Синхронизировать начальную версию — выполнено.** `twenty app apply --create --remote autonomus-local` успешно зарегистрировал и установил приложение: добавлено 7 сущностей, 7 файлов загружено.
6. **Проверить результат — выполнено.** В навигации workspace появилась ссылка `Autonomus Company`; страница открылась и показала стартовый экран приложения. Инструкции добавлены в README и SETUP пакета.

## Критерии готовности

- Пакет приложения существует отдельно от кода оркестратора, содержит собственный `package.json` и успешно устанавливает зависимости — **подтверждено**.
- CLI remote `autonomus-local` указывает на `http://localhost:3000`, аутентифицирован и привязан к workspace `Demo` — **подтверждено**.
- `twenty app apply --create --remote autonomus-local` завершился успешно — **подтверждено**.
- Приложение отображается в навигации локального Twenty workspace и его страница открывается — **подтверждено в браузере**.
- README и SETUP содержат инструкции для повторного локального запуска и синхронизации — **добавлены**.

## Итог

Локальный каркас создан, установлен и открыт в workspace `Demo` на `http://localhost:3000`. Широкие проверки (`lint`, `typecheck`, тесты) не запускались: задача ограничивалась созданием и локальной установкой приложения.

## Ограничения рабочего цикла

- Для последующих изменений использовать `twenty app apply`; не запускать `twenty app dev`.
- Не запускать широкую проверку типов, lint или интеграционные тесты без отдельного запроса.
- Не публиковать приложение в npm/marketplace: цель этого плана — локальная разработка.
- Хранить URL/учётные данные и ключи только в локальной конфигурации CLI, не добавлять их в пакет или репозиторий.
